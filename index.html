PROJECT BACKGROUND

About This Project

The Sleep Disorder Classification project demonstrates supervised machine learning classification using biometric and lifestyle data. By examining parameters like sleep duration, physical activity, blood pressure, and stress levels, our model classifies subjects into one of three outcomes: None (healthy), Insomnia, or Sleep Apnea.

Multiple classification algorithms were benchmarked on the clinical dataset, including Logistic Regression, Random Forest, and Support Vector Machine (SVM). The best-performing pipeline—an SVM with standard feature scaling and one-hot encoding—achieved 97.33% accuracy on the stratified test set.
